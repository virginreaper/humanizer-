Humanizer

Strips the usual AI tells out of text and nudges it toward your own writing style. Pure Python 3, no dependencies.

View on GitHub

Use it

python -m humanizer draft.txt
python -m humanizer --score draft.txt
cat draft.txt | python -m humanizer --seed 3

The first prints the rewritten text, with the score on stderr. The second only lists the AI tells found.

Also vocabulary (delve, pivotal, robust), chatbot residue, trailing -ing riders, em dash overuse and uniform sentence rhythm. Code fences are never touched.

Your voice

It learns from your own writing in samples/, one profile per kind: academic, essay, speech, personal. It keeps your curly quotes, dash style, British spelling and any phrase you really use. Run on your own samples, 94–100% of the words come back unchanged.

Limits

This is rule-based, not a language model. It removes patterns; it can't make dull writing good, and no tool can promise to beat a given AI detector. Read the output before you send it.
